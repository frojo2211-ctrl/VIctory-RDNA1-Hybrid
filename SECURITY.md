# Security Policy

## Reporting

If you find a security issue, please avoid posting exploit details publicly before maintainers can assess it.

## Scope

This project is an experimental compatibility/research codebase. Reports should focus on vulnerabilities in this repository's code/tooling, not on bypassing third-party protections.

## Out of scope

- Requests or reports intended to circumvent DRM, authentication, licensing, or platform protections.
- Reports that require proprietary copyrighted game assets to be shared.
